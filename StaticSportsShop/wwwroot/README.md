# Masters Sports & Events: static website (plain HTML)

No server code and no build step. Open `index.html` in a browser, or upload the folder to any web host.

- Pages: index, about, services, events, coaching, products, gallery, contact (all `.html`)
- `css/site.css`: the whole theme (colours are the variables at the top)
- `js/site.js`: navbar, gallery tabs and viewer; `js/contact.js`: contact form (EmailJS)
- Copy your photos into `images/` (see `images/README.txt`) and add `favicon.ico`.
- The navbar and footer are written into every page, so a change to them must be made in each file.
- Index carousel: edit the four `carousel-item` blocks in `index.html`.
